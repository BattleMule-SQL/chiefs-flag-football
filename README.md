# Team Page

A simple, view-only flag football team page hosted on GitHub Pages.

## Updating the page

All content lives in **`data.js`** — team name, colors, announcements, field locations, and the schedule.

1. Edit `data.js` (on github.com: open the file → pencil icon → edit → **Commit changes**).
2. GitHub Pages republishes automatically within a minute or two.

Tips:
- Dates are `YYYY-MM-DD`, times are 24-hour `HH:MM` (or `"TBD"`).
- Add `result: "W 28–14"` to a game once it's played; the record updates automatically.
- Set `pinned: true` on an announcement to keep it at the top.
- The "Next up" card picks the next event on or after today.
